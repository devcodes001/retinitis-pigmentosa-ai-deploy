# RPeyecare — Clinical AI Screening for Retinitis Pigmentosa

A full-stack Clinical AI platform for early detection of **Retinitis Pigmentosa** using deep learning retinal fundus image analysis.

## Features
- 🧠 ResNet-50 AI retinal scan analysis
- 👁️ Interactive RP Vision Simulator  
- 👤 Patient portal with screening history & clinic booking
- 🏥 Clinic portal for appointment management
- 🛡️ Admin console with user & clinic management
- 📑 Clinical PDF report generation
